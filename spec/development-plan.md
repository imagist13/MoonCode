## 二、开发阶段规划

### 阶段一：后端完善（预计 3-5 天）

**目标**：完善后端核心功能，确保生产可用

#### 2.1.1 文章-标签关联

| 任务 | 描述 | 验收标准 |
|:----|:-----|:--------|
| 领域层 | 在Article实体中添加Tags关联 | GORM many2many关系配置正确 |
| 仓储层 | 实现文章标签增删查询 | 支持添加/移除标签 |
| 服务层 | 实现文章标签管理逻辑 | 支持创建文章时关联标签 |
| Handler层 | 添加标签相关API端点 | 支持获取文章标签 |

#### 2.1.2 参数验证

| 任务 | 描述 | 验收标准 |
|:----|:-----|:--------|
| 集成validator | 配置go-playground/validator | 实现请求参数自动验证 |
| 自定义验证器 | 实现常用自定义验证规则 | 如密码强度、邮箱格式等 |
| 验证中间件 | 创建统一验证中间件 | 自动验证请求并返回标准化错误 |

#### 2.1.3 错误处理

| 任务 | 描述 | 验收标准 |
|:----|:-----|:--------|
| 错误定义 | 定义统一错误码和错误类型 | 错误码与HTTP状态码映射 |
| 错误中间件 | 创建全局错误处理中间件 | 捕获异常并返回统一格式 |
| 业务错误 | 完善各服务层错误处理 | 明确的业务错误信息 |

#### 2.1.4 Redis缓存优化

| 任务 | 描述 | 验收标准 |
|:----|:-----|:--------|
| 文章缓存 | 缓存文章详情和列表 | 提升查询性能 |
| 分类标签缓存 | 缓存分类和标签列表 | 减少数据库查询 |
| 缓存策略 | 实现缓存失效策略 | 支持更新时自动失效 |

#### 2.1.5 日志系统

| 任务 | 描述 | 验收标准 |
|:----|:-----|:--------|
| 日志库集成 | 集成Zap或Logrus | 结构化日志输出 |
| 日志中间件 | 创建请求日志中间件 | 记录请求耗时和状态 |
| 日志配置 | 支持不同环境日志级别 | 开发/生产环境区分 |

## 三、开发规范

### 3.1 代码规范

#### 后端（Go）

- 使用 `go fmt` 格式化代码
- 使用 `golangci-lint` 检查代码质量
- 函数注释使用标准格式
- 错误处理使用 `errors.Wrap`

#### 前端（TypeScript）

- 使用 ESLint 检查代码
- 使用 Prettier 格式化代码
- 组件命名使用 PascalCase
- 文件命名使用 kebab-case

### 3.2 Git规范

| 类型 | 前缀 | 示例 |
|:----|:-----|:-----|
| 功能 | feat | feat: add article search |
| 修复 | fix | fix: resolve login bug |
| 文档 | docs | docs: update API docs |
| 重构 | refactor | refactor: improve cache logic |
| 测试 | test | test: add unit tests |
| 样式 | style | style: update home page |

### 3.3 分支策略

- `main`：生产分支
- `dev`：开发分支
- `feature/*`：功能分支
- `bugfix/*`：修复分支
